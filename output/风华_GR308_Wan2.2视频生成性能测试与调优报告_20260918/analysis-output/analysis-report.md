# Wan2.2 报告证据审查

## 可直接使用的结论

- FP32 基线、Global FP16、M0-M3、S1-S2 均存在完整 `perf.json`，可以报告短测阶段耗时。
- S2 是当前成功短测中耗时最低且首帧质量通过的候选。
- Global FP16 的确定性图像损坏由三次同哈希输出和全参考指标共同支持。
- 121 帧/20 步没有成功 GR308 结果，不能报告该口径 E2E 性能。

## 必须保留的限定语

- “当前短测最优”，不能写成“生产最优”。
- “单帧质量接近”，不能写成“视频质量无损”。
- “疑似 allocator/VA 或 Conv3D workspace 问题”，不能写成唯一根因已经证明。
- RTX 5090 数据只作为外部参考，不能计算 GR308 性能占比。

## 数据完整性

- 有效短测：8 组核心配置，另有多次基线和 FP16 重复；
- 质量样本：1 prompt × 1 seed × 1 对齐首帧；
- 完整负载：0 个成功样本；
- 失败证据：容器日志中的 OOM、PAL、firmware semaphore 和 backend capability 错误。
