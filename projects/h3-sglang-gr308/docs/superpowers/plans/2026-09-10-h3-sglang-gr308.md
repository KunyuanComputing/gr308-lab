> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a guarded MiniMax H3 FL2VA validation through SGLang on GR308 and produce an H3-only correctness/performance report when native W4A8 dispatch is proven.

**Architecture:** Keep the existing Qwen SGLang adapter and upstream checkout read-only. Build an H3-specific overlay containing a Fantasy diffusion platform, an exact-source registry overlay builder, a native W4A8 dispatch gate, and guarded remote launch/benchmark scripts. Every stage fails closed and records evidence before the next stage runs.

**Tech Stack:** Python 3.10, pytest, PyTorch PrivateUse1/`torch_fant`, SGLang `multimodal_gen`, Comfy Kitchen W4A8, Docker Fantasy runtime, Bash, ffprobe, `fantgpu-smi`.

- [ ] **Step 3: Implement the minimal package and registry builder**

`registry_builder.py` must read the exact upstream file, require exactly one `musa` forced-map anchor, insert:

```python
"fant": "h3_sglang_fant.platform.FantasyDiffusionPlatform",
```

immediately after that anchor, reject a source that already contains the H3 entry, write the overlay, and return its SHA-256 digest. The CLI accepts `--source` and `--output`, prints JSON containing both paths and the digest, and exits nonzero on drift.

Use this implementation body:

```python
from hashlib import sha256
from pathlib import Path

ANCHOR = '            "musa": "sglang.multimodal_gen.runtime.platforms.musa.MusaPlatform",\n'
ENTRY = '            "fant": "h3_sglang_fant.platform.FantasyDiffusionPlatform",\n'


def build_registry_overlay(source: Path, output: Path) -> str:
    text = source.read_text()
    if ENTRY.strip() in text or text.count(ANCHOR) != 1:
        raise RuntimeError("SGLang diffusion registry anchor is missing, duplicated, or already patched")
    rendered = text.replace(ANCHOR, ANCHOR + ENTRY, 1)
    output.parent.mkdir(parents=True, exist_ok=True)
    output.write_text(rendered)
    return sha256(rendered.encode()).hexdigest()
```
