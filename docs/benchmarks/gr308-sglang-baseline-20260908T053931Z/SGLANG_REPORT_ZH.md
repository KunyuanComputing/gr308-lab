- 前置 sentinel：12/12；后置 sentinel：12/12。
- 补充长上下文压力测试 1024→256：1024/1024 成功，6.3534 output tok/s，持续 11.46 小时。该结果不进入 vLLM 稳定性同口径比较。

## 边界

- 固定 token、ignore_eos 的合成诊断，不是生产 SLA 或模型质量分数。
- n=3 的区间仅作描述，不支持细小差异的强推断。
- 本报告保留协议偏差数据并明确隔离，没有覆盖或删除原始证据。
